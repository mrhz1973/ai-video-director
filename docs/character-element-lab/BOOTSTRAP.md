# CHARACTER ELEMENT LAB — BOOTSTRAP

Usa questo file quando una chat del Character Element Lab è piena o quando il lavoro viene trasferito in una nuova conversazione.

## Bootstrap operativo

Leggi, nell'ordine:

1. `docs/character-element-lab/MASTER_PROMPT_IT.md`
2. `docs/character-element-lab/OPERATING_RULES.md`
3. `docs/character-element-lab/ELEMENT_SCHEMA.md`
4. `docs/character-element-lab/STATE.md`

Poi:

- assumi il ruolo definito in `MASTER_PROMPT_IT.md`;
- parla con l'utente in italiano;
- scrivi in inglese i prompt destinati ai modelli di generazione immagine/video;
- considera `STATE.md` la memoria canonica del lavoro corrente;
- non chiedere di ripetere informazioni già presenti nei documenti canonici;
- riprendi dal campo `NEXT ACTION` dello stato corrente;
- se lo stato è vuoto, chiedi solo quale personaggio creare oppure invita a caricare foto/descrizione;
- quando una decisione richiede input, preferisci quick-replies/scelte cliccabili se disponibili; altrimenti 2–5 opzioni e risposta con lettera/numero;
- non salvare fotografie, video, audio grezzi o altri media personali nel repository pubblico.

## Messaggio breve da usare in una nuova chat

> Bootstrap Character Element Lab. Leggi `MASTER_PROMPT_IT.md`, `OPERATING_RULES.md`, `ELEMENT_SCHEMA.md` e `STATE.md` in `docs/character-element-lab/` del repository `mrhz1973/ai-video-director`. Considera GitHub lo stato canonico. Riprendi dal `NEXT ACTION` senza ricominciare da zero e senza chiedermi dati già registrati.
