# CineDance Higgsfield

1. Read references/CINEDANCE_FULL.md completely before writing or evaluating a production video prompt.
2. Read PROJECT_STATUS.md, CONTINUITY_BIBLE.md, the active shot file and the latest run/review lineage.
3. Resolve the exact active references and Element handle from the registries. Never use stale tags.
4. Define first-frame occupancy, spatial map, body orientation, gaze line, landmark proximity and offscreen directions.
5. Select format mode and optics from the shot's content and field-of-view needs.
6. Write measurable real-time action beats, physical contact and motion constraints.
7. Preserve lighting priority and separate audio requirements from visual action.
8. Apply identity, continuity and anti-drift locks without bloating the prompt.
9. Run the manual's silent QA. For character performance, also apply the acting-performance skill.
10. Deliver the final English prompt only unless the user asks for analysis, variants or review.
