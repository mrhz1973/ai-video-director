# Lira image prompts

1. Read references/LIRA_FULL.md completely before constructing or repairing a project image prompt.
2. Read the active project reference hierarchy and identify the exact source image role.
3. Route the task to the correct model and lane before writing.
4. Separate the minimal requested change from an exhaustive preserve list for edits.
5. Keep identity, tattoo, text and anatomy constraints role-specific; do not let descriptive prose compete with exact references.
6. Put aspect ratio and resolution in platform settings, not prompt prose.
7. Prefer concise natural instructions over keyword stacking and long negative lists.
8. Verify subject count, framing, light, camera, palette, references and known failure modes.
9. Return the production-ready English prompt plus only the brief application notes the user needs.
